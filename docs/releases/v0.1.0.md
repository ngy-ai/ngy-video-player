# 影匣 0.1.0

首个公开版本。界面用 [gpui-kit](https://crates.io/crates/gpui-kit)（Zed 的 GPUI），
解复用、解码、音视频同步、字幕排版交给 libmpv，Windows / macOS / Ubuntu 同一套 Rust 代码。

## 下载

| 文件 | 适用 |
| --- | --- |
| `ngy-video-player-v0.1.0-windows-x86_64.exe` | Windows 10 / 11 x64，单文件，免安装 |

- 单文件分发：libmpv 已内嵌进 exe（约 127 MB，其中约 116 MB 是库），拷到任意一台没装过
  mpv 的机器上双击就能播，不需要在 exe 旁边摆 dll。
- 不依赖系统 VC++ 运行库：MSVC 运行库静态链接，干净系统上不会弹「找不到
  VCRUNTIME140.dll」。
- 首次启动会把内置的库解压到 `%LOCALAPPDATA%\ngy-video-player\libmpv\`，之后直接复用。

产物由 CI 构建（`.github/workflows/release.yml`），本次的 SHA-256 由工作流在构建完成后
自动追加在文末，页面上每个资产的摘要也能对照。

macOS / Linux 暂不提供预编译包，需要自行构建（macOS 要经
`bash scripts/bundle-macos.sh` 打成 `.app` 才能注册文件关联）：

```bash
./scripts/fetch-libmpv.sh
cargo build --release
```

## 能放什么

「能放什么」直接等于 mpv 能放什么：MKV / MP4 / MOV / AVI / WMV / FLV / TS / M2TS /
MPEG / VOB / OGV / 3GP / RMVB / WebM / MXF / ISO 蓝光原盘，H.264 / H.265 / AV1 / VP9 /
ProRes / DNxHD / MPEG-2 等编码；纯音频（FLAC / APE / DSD / Opus / AAC / MP3 …）也走
同一条路。

## 功能

- **播放列表**：拖入文件、目录、`.m3u` / `.m3u8` / `.pls`；目录自动展开并按自然序排列
  （`第2集` 在 `第10集` 前面）；拖单个文件时同目录的其它媒体自动排队；行内右键可删除、
  定位文件、查看格式。
- **画面设置**：比例、旋转、镜像，三项都随偏好保存。
- **视频设置**：渲染模式（性能 / 稳定）、解码方式、播放显卡（仅 Windows 可列出）。
- **播放设置**：循环模式、窗口置顶三档（不置顶 / 播放时 / 总是）。
- **迷你小窗**：独占任务栏的悬浮窗口，控制条与音量滑块随鼠标浮现，可随时置顶。
- **截图**：`S` 抓取解码后的原始分辨率画面，存到 `图片/影匣截图/`，画面左上角浮出
  「复制 / 打开 / 定位」卡片；连拍不互相覆盖。
- **文件关联**：一次登记 60 个格式（54 视频容器 + 6 播放列表），可撤销、可设启动时自动维护。
- **统一设置窗口**：画面 / 视频 / 播放 / 文件关联 / 快捷键五个标签页，改动即时生效并落盘。
- **悬浮提示**：控制条、左栏、小窗上的图标按钮悬停显示文字说明。

## 已知限制

- 主画面走 mpv 的软件渲染（`MPV_RENDER_API_TYPE_SW`）：1080p60 无压力，4K120 这类
  极端场景会被 CPU 回读拖住；硬件后端接口已预留。
- HDR（PQ / HLG）目前按 SDR 输出，颜色会偏。
- 硬件解码默认关闭：软件渲染下 hwdec 要把帧从显存倒回内存，通常更慢；需要时可在
  「视频设置」页切换。
- 单文件版体积约 130 MB（内嵌 libmpv），不想要这个体积可以
  `NGY_EMBED_MPV=0 cargo build --release` 改回「库放在 exe 旁边」。
- Windows 上无法静默抢默认播放器：程序只能把自己送进「默认应用」列表，最后一下要用户点。
- macOS 包暂时没有应用图标，Dock 里是通用图标。

## 反馈

播放异常请附上 `%LOCALAPPDATA%\ngy-video-player\logs\` 下的日志；`NGY_MPV_VERBOSE=1`
可以输出 libmpv 的详细日志。
