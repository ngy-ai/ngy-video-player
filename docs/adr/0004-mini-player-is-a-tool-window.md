# 小窗是工具窗口，不进任务栏与 Alt+Tab

小窗用 `WindowKind::PopUp` 创建，在 Windows 上落到 `WS_EX_TOOLWINDOW | WS_EX_TOPMOST`：任务栏和 Alt+Tab 里都看不到它。

选它的理由是小窗模式的定义——同一时刻只有主窗口或小窗之一可见。如果小窗是普通窗口，任务栏会同时出现「最小化的主窗口」和「小窗」两条同一个应用的记录，而用户从任务栏点回主窗口正是约定的「还原」手势，多出一条会让这个手势失去唯一性。

代价是这条路径在 Windows 上没有 `WS_THICKFRAME`，gpui 自绘的缩放边框只在窗口上边缘生效，左右下三条边拖不动。小窗的尺寸本来就写进首选项、且高度按画面比例锁定，四边缩放并非必需能力——但这不代表它是免费的，不要当成 bug 去「修」。
