# 小窗是独立窗口，不是主窗口缩小

小窗模式用第二个窗口承载画面，进入时主窗口不再可见。曾被考虑的替代做法是「把主窗口自身缩到小窗尺寸」——那不需要隐藏任何东西，架构上更省。

选择独立窗口，是因为主窗口已经是不带系统装饰的自绘窗口，它的一整套布局（菜单栏、播放列表、控制栏）都以「窗口足够大」为前提。若改为缩放同一窗口，就必须在运行时把整棵界面树切换成紧凑布局，还要在还原时补回面板展开状态；同时窗口尺寸剧变会让 mpv 反复重设渲染目标，播放中会有可见的抖动。独立窗口则可以原样保留主窗口的一切状态，还原是瞬时的。

代价是必须解决「主窗口不可见」，而这个能力 gpui 只提供了最小化，没有隐藏单窗口的 API。
